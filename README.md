## Features

### Customer

Customers can:

- Browse available beverage products
- View product details
- Search and explore the product catalog
- Manage their own account
- Interact with the store through the customer interface

### Administrator

Administrators have full management access to the application and can:

- Manage products and product information
- Add, edit, and remove products
- Manage customer accounts
- Manage other user accounts and their roles
- View and manage application data
- Perform administrative operations across the system

### User Roles & Access Control

The application implements role-based access control with different permissions for customers and administrators.

- **Customer:** Access to customer-facing functionality and their own account
- **Administrator:** Full access to administrative functionality, including user and product management

This approach ensures that users can only access functionality appropriate to their assigned role.

## Application Management

DrinkStore includes an administration system that allows administrators to manage the core entities of the application from a centralized interface.

Administrators can manage:

- Products
- Customer accounts
- User accounts
- User roles and permissions
- Store-related data

This provides a clear separation between regular customer functionality and administrative operations.

- Role-based access control
- User and account management
- Authorization and permissions
- Building administrative interfaces
- Managing application entities through CRUD operations
